- 大家好，我是 **StarsOfDeduce**，一名专注 Windows 工具与桌面交互的独立开发者 🌌
- **[Aplomb](https://github.com/StarsOfDeduce/Aplomb)**：按可见边框精确对齐、支持缩略图选择器的窗口居中工具 🎯
- **[Tar V](https://github.com/StarsOfDeduce/Tar-V)**：以毛玻璃拟物视觉重新组织常用入口的 Windows 快捷启动面板 🚀
- 持续探索 Win32、PySide6、C++、Electron 与系统级交互改造 🛠️
- 重视清晰的层级、克制的动效，以及真正减少操作成本的软件 ✨
- 开发过程与技术思考记录在 **[个人博客](https://starsofdeduce.github.io/)**，欢迎交流与反馈 🍨
